Topic Instant Messenger

## Getting started

```bash
pnpm install
pnpm setup:env
pnpm dev
```

This runs both services at once: `chat` on [localhost:3000](http://localhost:3000), `realtime-server` on [localhost:2428](http://localhost:2428).

See `CLAUDE.md` at the root (including its "Local environment setup" section) and in each app for architecture details and conventions.
